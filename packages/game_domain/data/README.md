# Bundled dictionary data

`enable1.txt` is the ENABLE 1 English word-game list, downloaded from:

https://raw.githubusercontent.com/dolph/dictionary/master/enable1.txt

The ENABLE word list is in the public domain. This repository pins the exact bytes as dictionary `enable1-en`, version `1`, with SHA-256:

`3f16130220645692ed49c7134e24a18504c2ca55b3c012f7290e3e77c63b1a89`

Changing the file, normalization, identifier, or checksum requires a new dictionary version so persisted games remain replayable.
